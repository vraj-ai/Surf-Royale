# Production Decision 004 — Set the Live-Service Budget and Launch Mode Scope

**Type:** Wayfinder grilling decision  
**Status:** open; intentionally blocked  
**Blocked by:** P3 complete reduced-scale match evidence

## Question

What approved monthly service/moderation budget and launch-mode scope make a 50–60-player online v1 operable by one developer?

## Why it is not answered now

The current repository has no production-shaped match, concurrency evidence, retention data, or provider workload estimate. Choosing providers or claiming Solos + Duos are solo-operable before P3 would be false precision. P0 needs no external service.

## Default to test later

Keep Solos + Duos as the GDD destination, but require P4 to present a costed one-mode fallback if hosting, moderation, party/voice, or concurrency evidence exceeds the user's approved envelope.
